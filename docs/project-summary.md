# Project Summary

## Service Direction

WhyHouse는 아이 관점에서 아파트 주변 생활 인프라와 보행 안전 정보를 제공하는 서비스입니다.

## MVP Scope

- Initial area: 신정1동, 신정4동
- Backend role: FastAPI 기반 API 서버
- Initial responsibility: health check, apartment lookup, nearby infrastructure lookup, child safety insight, route insight

## Current Development Phase

현재 단계는 백엔드 초기 개발 환경 구축입니다.

- FastAPI 애플리케이션 진입점 구성
- 환경 변수 기반 설정 로딩
- 구조화 로그
- Docker Compose 기반 로컬 MSA 실행 구조
- 최소 health check 테스트

개발 단계 추적 문서는 실제 Phase별 작업 계획이 확정될 때 `docs/development-phases.md`로 생성합니다.
